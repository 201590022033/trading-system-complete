# ADR 0055 - Standard Bank primary JSE research onboarding

Accepted, 6 October 2026. The owner chose Standard Bank OST ahead of Yahoo after repeated JSE Yahoo OHLC inconsistencies. This change applies to the daily JSE research and paper input lane once a local OST export has been installed. Public display charts and CFD references remain separately labelled.

Dataset v3 stores one whole OST series per instrument, with raw CSV SHA256, actual capture timestamp, source identity and explicit unverified action/price/volume/availability definitions. The import is available only from the local dashboard after the owner has signed into OST directly in the browser and selected exports. It never receives a bank username, password, session cookie, account or position data. The CLI uses a private ignored manifest as an alternative. A bounded batch validates before saving and retains the old latest dataset. Four-day source expiry and identical-hash idempotence prevent upload freshness from renewing an old export. The existing collector uploads v3 on schedule without polling OST or Yahoo once primary is activated. The hosted import endpoint remains disabled.

For v3, the uploaded worker fetcher and on-demand JSE opportunity refresh use only current OST charts. Instruments lacking an export are unavailable; canonical Yahoo snapshots already frozen remain historical records. Provider identity participates in paper source-session deduplication. New frozen technical records carry the OST receipt; past provider decisions cannot mature against a different feed. Strategy definitions, orders and live execution are unchanged. Historical AI comparisons and new model proposals are blocked while OST adjustment/action, volume and historical availability contracts remain unverified. This is a conservative research-source cutover, not B5 real-data admission.

The observed OST history format is cents-based HLCV. Open is null unless an actual Opening (c) column exists in a source export. Inconsistent high/low/close observations are retained and counted, not silently repaired. Gold and USD/ZAR need separate product/currency/volume contracts and are shown as pending context sources. Broader unattended acquisition needs an authorized OST batch export or API; broker browser login cannot be assumed by a scheduled server.

The prior v1/v2 readers remain compatible. New v3 is explicitly opt-in by installing an OST export. Admission and prospective learning depend on later provider evidence and real subsequent sessions.

Native OST **Save To Excel** downloads are HTML price-history tables with an `.xls` extension. The importer reads only the history grid, hashes and retains the original bytes, and validates numerical values for the latest 600 completed sessions. Older rows are outside the bounded research window. Genuine sector exports for STXFIN, STXRES and STXIND, plus Naspers, were imported and uploaded without creating opening prices or repairing HLC anomalies.
