# ADR 0044 — Reconcile current guidance without rewriting historical evidence

Date: 2026-10-05. Status: Accepted. Documentation-only decision.

## Context

Two weeks of canonical paper, profile, data, AI research and news changes left the root README and operational guides describing earlier systems/machines. Accumulated milestone notes contained multiple historical ACTIVE labels. The owner's intended local six-family loop was easily confused with the narrower implemented cloud hypothesis lane.

## Decision

Publish one dated CURRENT_STATE snapshot and a complete DOCUMENTATION_INDEX. Rewrite current architecture, setup/runbooks and roadmap against source/acceptance evidence. Preserve the replaced texts as dated history. Give original module contracts, decision records, handoffs and reports an explicit current-context note without changing their recorded historical findings. Do not edit the eleven protected Markdown artifacts or the other checksum-protected benchmark files.

Distinguish IMPLEMENTED from VALIDATED and current behavior from owner-proposed target behavior. Preserve profile 1.0.1 as canonical, exact-version research attribution, data-quality exclusions, single-publisher news waiting states and disabled Live execution. Record settings as checkpoint observations, never expose secrets or claim a live configuration refresh that this task did not perform.

## Consequences

Current guides are coherent and older evidence remains inspectable. More historical files are retained, but they are explicitly labelled and indexed. Mandatory governance reading order is unchanged. No runtime code, migrations, schedules, providers, model calls or broker state are changed. Future tasks update current guidance and dated change notes rather than prepending competing current states indefinitely.
