6 October 2026. The local onboarding status now exposes `prospective_outcomes` for each OST and IRESS instrument separately. The evaluator reads only actual dated capture files. Each capture's newest completed session can become a first-seen anchor; older history within that file is comparison context. A 3/4/5 observed-session exit must have been first seen in a later capture. Revisions to an entry or exit are reported and excluded from the clean cohort. The reported net percentage deducts an illustrative 10 basis points round trip; it is neither an actual fill nor a risk-adjusted strategy result.

At implementation time the local capture folder had no files. Accordingly the correct current result is zero cohorts, not a measured win rate. The engine can label future captures autonomously after imports, but it cannot create missing observations. The dashboard API exposes sample, positive, pending and revision-excluded counts plus the mean only when clean samples exist. Horizons count observed sessions; exchange-calendar completeness and corporate-action basis remain unverified. Small or irregular samples must not be used for strategy promotion.
