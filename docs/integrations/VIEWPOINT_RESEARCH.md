# Standard Bank / IRESS ViewPoint Research

Accessed 2026-09-04. Confirmed facts are separated from unknowns.

## Confirmed

Standard Bank's OST page identifies the product as Standard Online IRESS
ViewPoint and requires an OST login/registration. It describes web access,
real-time data, charting, alerts, order handling and compliance integration:
https://onlinesharetrading.standardbank.co.za/pages/OST/ViewPoint.html

Standard Bank is moving OST, Webtrader and AutoShare Invest clients to Shyft:
https://www.shyft.co.za/en-ZA/shyft-trading-platforms-migration

IRESS/QuantHouse markets low-latency API data feeds and trading infrastructure
to institutional customers such as banks, brokers and venues:
https://www.quanthouse.com/

## Unknown / requires written confirmation

- A documented ViewPoint API available to ordinary retail OST customers.
- REST, websocket, FIX or streaming credentials exposed by Standard Bank.
- Authentication details beyond normal customer login.
- Permission to ingest subscribed quotes into this private application.
- Exact current Level 1/Level 5 prices, depth entitlement, asset coverage, and
  ViewPoint retirement date after migration.

Institutional IRESS API availability does not prove retail entitlement.
Authenticated browser endpoints are discovery evidence only and were not
inspected or automated. ViewPoint should be treated as a transition/data
candidate, not a durable execution dependency, until Standard Bank responds.
