# Architecture entry point

The current architecture is described in [CURRENT_ARCHITECTURE](docs/architecture/CURRENT_ARCHITECTURE.md), with the owner's intended next workflow in [TARGET_ARCHITECTURE](docs/architecture/TARGET_ARCHITECTURE.md). The [current state](docs/CURRENT_STATE.md) distinguishes deployed capabilities, blocked data and proposed research.

The canonical path reuses existing components: M13 opportunities → M14 policy → M15 risk veto → paper sizing and broker → durable outcomes. M16 strategy targets and immutable strategy profile references provide separate evaluation/lineage contracts. Research versions do not replace the default profile, ranking or safety controls.

The home PC retains daily data and runs local news analysis. Railway serves dashboard/API state, persists the ledger and performs bounded research comparisons. A local six-hypothesis engine and selective 30-minute radar workflow remain planned. LIVE execution stays disabled.

The earlier large design proposal is preserved in [the historical architecture snapshot](docs/history/ARCHITECTURE_PRE_2026-10-05.md). Its proposed multi-agent UI and migration sequence are historical design context, not an inventory of running services.
